# Data Analysis Skill

A skill for analyzing datasets and extracting insights.

## Description

This skill provides capabilities for:
- Exploratory data analysis
- Statistical analysis
- Pattern recognition
- Data visualization planning
- Result interpretation

## Instructions

When analyzing data:

1. **Initial Exploration**
   - Understand data structure (rows, columns, types)
   - Check for missing values
   - Identify outliers
   - Calculate basic statistics (mean, median, std dev)

2. **Statistical Analysis**
   - Choose appropriate methods based on data type
   - Consider correlations between variables
   - Test hypotheses if applicable
   - Calculate confidence intervals

3. **Pattern Recognition**
   - Look for trends over time
   - Identify clusters or groupings
   - Detect anomalies
   - Find relationships between variables

4. **Interpretation**
   - Contextualize findings
   - Consider limitations
   - Suggest further analysis
   - Communicate insights clearly

## Common Analysis Types

### Descriptive Statistics
- Mean, median, mode
- Standard deviation, variance
- Min, max, quartiles
- Frequency distributions

### Inferential Statistics
- Hypothesis testing
- Confidence intervals
- Regression analysis
- ANOVA

### Exploratory Analysis
- Correlation analysis
- Cluster analysis
- Dimensionality reduction
- Time series analysis
