# Web Search Skill

A skill for performing web searches and extracting information from search results.

## Description

This skill provides capabilities for:
- Formulating effective search queries
- Analyzing search results
- Extracting relevant information
- Citing sources properly

## Instructions

When using this skill:

1. **Formulate Clear Queries**
   - Use specific keywords
   - Consider using Boolean operators (AND, OR, NOT)
   - Include relevant context terms

2. **Analyze Results**
   - Review top 5-10 results
   - Evaluate source credibility
   - Look for consensus across sources
   - Note publication dates

3. **Extract Information**
   - Focus on factual data
   - Capture key quotes
   - Note author/organization
   - Record URLs for citations

4. **Cite Sources**
   - Use format: [Source Name](URL) - Date
   - Include author if available
   - Note last accessed date

## Best Practices

- Cross-reference information across multiple sources
- Prioritize authoritative sources (.edu, .gov, established organizations)
- Be aware of publication bias
- Check for recent updates on time-sensitive topics
- Distinguish between facts, opinions, and speculation
